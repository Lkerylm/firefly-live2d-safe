# Live2D Official Sample Models (runtime assets only)

This repository serves the **runtime files only** (`*.moc3`, `*.model3.json`, textures, motion/physics JSON)
of sample characters published by **Live2D Inc.**, so that a web page (https://lkerylm.github.io/) can load and
display them in a browser.
